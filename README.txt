FKK Strand Finder – Version 13

WICHTIG:
Version 13 verwendet absichtlich KEINE Live-Overpass-Abfrage mehr im Browser.
Damit hängt die Suche nicht mehr davon ab, ob ein öffentlicher Overpass-Server bei
40–100 km gerade erreichbar oder überlastet ist.

Die App berechnet die Entfernung zu einer festen, kuratierten Datenbank mit
9 dokumentierten FKK-Orten im Norden Deutschlands.

Installation auf GitHub Pages:
1. index.html ersetzen
2. style.css ersetzen
3. app.js ersetzen
4. Seite neu laden

Danach:
- „Meinen Standort verwenden“ drücken
- Radius z.B. auf 50 km oder 100 km stellen

Die Kartenkacheln kommen weiterhin von OpenStreetMap. Die FKK-Suche selbst läuft
komplett lokal im Browser.

Hinweis:
Einträge mit „FKK-Verzeichnis“ stammen aus aktuellen FKK-Badesee-Verzeichnissen.
Einträge mit „offizielle Quelle“ sind zusätzlich durch eine kommunale oder
Betreiberquelle dokumentiert. Regeln, Sperrungen und Öffnungszeiten können sich
ändern; deshalb zeigt die App die Quelle je Eintrag an.
