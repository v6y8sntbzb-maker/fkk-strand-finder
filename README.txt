FKK Strand Finder – Version 9

Geschwindigkeit verbessert:
- Bis 40 km: nur EINE kompakte Overpass-Abfrage.
- Über 40 km: vier Teilbereiche werden PARALLEL abgefragt.
- Timeout pro Teilabfrage nur 12 Sekunden.
- Wenn Live-Overpass langsam/unerreichbar ist, werden bekannte FKK-Orte trotzdem angezeigt.
- Die Karte und der Standort erscheinen sofort, ohne auf die FKK-Suche zu warten.

Installation:
index.html, style.css und app.js auf GitHub Pages ersetzen.
